# Service Request Priority Alert Tool

This project demonstrates a small Python automation tool for identifying urgent open service requests.

It reflects the type of structured coordination, tracking, and operational support work I have contributed to in previous roles, recreated here using fictional data for demonstration purposes.

## What the tool does

The script reads a service request dataset and automatically filters requests that are:

- High priority
- Still open in the workflow

It then:

- prints a summary of urgent cases
- saves the filtered requests into a new CSV file

## Example output

The tool highlights requests that may require immediate follow-up, helping teams quickly identify urgent operational issues.

## Files included

- `data/service_requests.csv` — simulated service request dataset
- `data/urgent_requests.csv` — filtered urgent requests generated by the script
- `python/priority_alert.py` — Python automation script
